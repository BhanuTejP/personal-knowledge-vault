# Welcome to Your Vault

Your **personal knowledge vault** is ready — PARA + GTD + Dataview dashboards.

## First Steps

1. Install these **community plugins** (Settings → Community Plugins → Browse):
   - **Dataview** — powers all dashboards
   - **Tasks** — global task management
   - **Templater** — smart templates
   - **Calendar** — visual daily notes calendar
   - **Periodic Notes** — weekly/monthly/yearly notes
   - **Kanban** — project board view
   - **Homepage** — auto-open dashboard on launch

2. Configure plugins (see README for exact settings)

3. Set **Homepage** plugin to open `11-Dashboards/Homepage`

4. Open your first daily note: `Cmd/Ctrl + P` → "Open today's daily note"

5. Start capturing everything in `00-Inbox/`

## Key Shortcuts

| Action | Shortcut |
|--------|----------|
| New note | `Cmd/Ctrl + N` |
| Open daily note | `Cmd/Ctrl + P` → "daily" |
| Insert template | `Cmd/Ctrl + P` → "template" |
| Search vault | `Cmd/Ctrl + Shift + F` |
| Graph view | `Cmd/Ctrl + G` |
| Command palette | `Cmd/Ctrl + P` |
